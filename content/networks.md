# Networks

Networks allow computers and devices to connect and share data. In our project, networks are essential because the AI module needs to communicate with other parts of the system to send and receive information.

**Key Terms:**
*   **IP Address:** A unique number given to each device on a network so it can be identified.
*   **Protocol:** A set of rules that devices follow to communicate with each other (like HTTP for web pages).

### Worked Example: Sending a Message
If Computer A wants to send a file to Computer B on the same network:
1. Computer A finds Computer B's IP address.
2. The file is broken down into small data packets.
3. The packets are sent through the network using a protocol (like TCP).
4. Computer B receives the packets and puts them back together to get the original file.

### Question and Answer
**Question:** What is the main difference between the Internet and a local network (LAN)?
**Answer:** A local network (LAN) connects devices in a small area (like a house or school), while the Internet is a massive global network connecting millions of smaller networks together.
