# Aero AI: Module Outline
## Hardware, Networks & Behaviorist AI

**Team:** Aero AI  
**Course:** Introduction to Artificial Intelligence and Computer Science  
**Module:** Module 2 — Hardware, Networks & Behaviorist AI  
**Intended learners:** Beginners studying computer science and artificial intelligence.

## 1. Module Overview

This module introduces the physical components of computers, the networks that allow devices to communicate, and the behaviorist approach to artificial intelligence. It connects computer hardware and communication systems with the basic idea of intelligent agents learning from their environment.

## 2. Learning Outcomes

By the end of this module, learners should be able to:

1. Identify the main components of computer hardware and explain their functions.
2. Distinguish between memory and storage and describe how the CPU, memory, input, and output work together.
3. Explain basic networking concepts, including IP addresses, protocols, LANs, and the Internet.
4. Describe how information travels between devices across a network.
5. Define agents, environments, stimuli, responses, rewards, and reinforcement.
6. Explain how feedback and rewards can influence an agent's behavior.
7. Compare the roles of hardware, networks, and behaviorist AI in a practical example.

## 3. Prerequisites

Learners should have:

- Basic computer literacy.
- An understanding of what computers and digital devices are.
- No previous programming or advanced mathematics experience is required.

## 5. Connections Between the Topics

The three topics will be connected through a practical example of a robot:

- **Hardware:** Sensors, a processor, memory, and motors allow the robot to receive information and act.
- **Networks:** Communication systems can allow the robot to exchange information with other devices.
- **Behaviorist AI:** The robot can adjust its behavior based on feedback or rewards.

This example will help learners understand how physical components, communication, and behavior-based decision-making can work together.
