## Project purpose

This repository holds the shared Markdown content for Aero AI Academy, a connected set of beginner learning materials: a Study Guide, a Test Bank, classroom slides and video tutorials. The Markdown is the common source for all of them. It explains how computers work, how devices communicate, and how an AI agent can learn from rewards and penalties.

## Intended learners

Beginners in an introductory computer science and AI course. Learners only need everyday experience of using a computer and the internet. No programming, networking or AI knowledge is assumed.

## Learning goals

After working through this module, a learner can:

1. Identify the main hardware components and explain what each one does.
2. Explain the difference between memory (RAM) and storage.
3. Explain how devices exchange data using IP addresses, packets, protocols, switches and routers.
4. Trace how a website loads and find the mistake in a simple network problem.
5. Explain how an agent learns from rewards and penalties, and calculate a cumulative reward.
6. Explain exploration versus exploitation and why the current state matters.
7. Combine ideas from all three topics to explain one everyday scenario.

## How to use the materials

- All content is plain Markdown. Open the files directly on GitHub, where they display formatted, or in any text editor or Markdown viewer.
- No installation is needed. Every activity in the Markdown files can be done with the text alone.
- Each activity has its answers and explanations directly below it. Try the activity first, then compare.
- The Test Bank lists all questions first and the answer key with explanations after them.
- The diagrams in these files are text-based. Image versions of the diagrams, the printable worksheets and cut-out cards, and the optional hands-on labs (Task Manager, ping and traceroute, Little Man Computer, Cisco Packet Tracer) are in the Study Guide package.

## Known limitations

- The module covers three topics at an introductory level. It does not teach programming, network configuration or how to implement reinforcement learning algorithms.
- Diagrams in the Markdown files are text-based.
- Some links in the references are external websites. They are for further reading and are not needed to complete any activity. Some may not open in every country.
- Cisco Packet Tracer needs a free Cisco Networking Academy account. The activity has an offline fallback in the Study Guide.
- The robot-maze activities use a small, simplified environment to teach the ideas. Real reinforcement learning systems are much larger.
